# Support expectations

Stickonfig is provided as open-source community software. The original author does not provide installation, website integration, hosting, configuration, or production support.

If you use Wix, Squarespace, WordPress, Shopify, another CMS, or a custom website, provide this repository to your existing web developer or site administrator and ask them to determine the best integration method for your site. Often a link to a separately hosted configurator is the simplest choice.

GitHub issues may be used for reproducible bugs and suggestions. Issues are not guaranteed to receive a response, pull requests are not guaranteed to receive review, and no service-level commitment exists. Individual store integrations, checkout setup, printer/RIP troubleshooting and ongoing store maintenance are outside the project's scope.

You are welcome to adapt the code or hire someone to help you. Please test your configuration, pricing, security and production files before putting a shop instance into service. No hosted account, installation service, paid service, or automatic artwork-improvement service is included.

Stickonfig is independent. Annex Brands, PostalAnnex and affiliated franchise systems do not develop, maintain, sponsor, endorse or support it.
