# Contributing

Bug reports and pull requests are welcome, with no guarantee of a response or review.

1. Describe the browser, steps, expected output and actual output. Use a minimal generated fixture.
2. Never submit proprietary customer artwork, personal data, credentials, or store-specific secrets.
3. Run `npm test`, `npm run build`, `npm run test:browser`, `npm run audit:licenses` and `npm run audit:public` for relevant changes. Inspect proof/PDF output when changing geometry or rendering.
4. Preserve separation of configuration, price policy, processing and submission. Do not add a mandatory hosted service.
5. Keep dependency licenses compatible with redistribution. No AGPL additions without explicit project discussion. Include licenses and attribution for any new sample assets.

By contributing, you agree that your original contribution may be distributed under the project's MIT license and confirm you have the right to submit it. Please keep changes focused and document any production-output differences.
